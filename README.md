# Skånes Väderkarta

Webbapplikationen **Skånes Väderkarta** är utvecklad för att visualisera aktuellt väder i Skåne på en interaktiv karta. Projektet bygger på en mashup av API:er där data hämtas dynamiskt med JavaScript och presenteras visuellt med hjälp av Leaflet. Applikationen är responsiv och fungerar både på desktop och mobila enheter.

På sidan kan användaren söka efter en plats i Skåne via ett textfält och se platsen markerad på en dynamisk karta. Vid sidladdning visas fördefinierade städer med färgkodade markörer baserat på temperatur, tillsammans med dynamiska popup-fönster som visar aktuell väderinformation. 

All styling och layout har implementerats med SCSS (SASS), där variabler, mixins och animeringar används för att skapa en modulär, konsekvent och interaktiv design.

## Funktioner

- Interaktiv karta över Skåne med Leaflet  
- Visar aktuellt väder för fördefinierade städer vid sidladdning  
- Sökfunktion för att visa väder på specifik plats  
- Dynamiska markörer med temperatur och väderbeskrivning  
- Färgkodade markörer baserat på temperatur  
- Responsiv design för både mobil och desktop  
- Laddningsindikator vid API-anrop  
- Subtila animationer och hover-effekter för bättre användarupplevelse  

## Tekniker

- JavaScript
